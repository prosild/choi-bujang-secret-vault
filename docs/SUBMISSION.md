# 제출 준비 기록

## 현재 제출: 11단계 저장점 (10단계 기록은 아래)

1) 안전 정책을 사본으로 보관하고 시험 사본 한 줄만 바꿔 복원했습니다. 실행 전에 버전과 변경 범위를 표시하고, 복원 직전 사본·해시·버전·확인 계획을 다시 검증합니다.
2) B 한 건 전용 복원 POST 경로를 유지하고 반환값 검증을 추가했습니다. 정책 복원 뒤 로컬·모의 검사 38개와 판정기·재인증·탐지·빌드 검사가 통과했습니다. `npm run backup` / `npm run restore` 명령을 추가했고, `npm run bundle`이 사본 재검증·변조 백업 거부·복구 후 재시험을 실제로 다시 실행해 제출 묶음에 기록합니다.
3) 실제 DB에서 가상 B 한 건의 변조·삭제 복구와 ID·소유자·내용 해시 일치, 잘못된 사본·소유자·대상 거부를 확인했습니다. 다른 메모·기존 감사 기록을 보존했고 시험 변경을 롤백했습니다. 실제 B의 서명된 복원 HTTP 왕복과 운영 엔진 재공격은 미실행입니다. 심판 제출은 사용자가 직접 합니다.

현재 제출 JSON은 `npm run bundle`이 생성한 `artifacts/submission.json`입니다. 아래는 이전 6~12단계 작업 당시의 제출 초안이며, 10단계 실DB 시험 관련 문구는 2026-11-06 실제 SQL 시험 PASS 이후 상태로 고쳤습니다.

## 공통 제출 문구

1) 기존 서버 로그인과 본인 메모 CRUD를 유지하고 기기 등록 판정, 추가 인증, 자원별 경로 제한, 조회 폭주 탐지를 추가했습니다.
2) 정책 시험 사본 복원과 B 메모 한 건 복원, 설치 화면, 서버 집계 작전실, XDR 6종을 구현했습니다.
3) 자동 테스트 38건과 배포 API 점검 9건이 통과했습니다. 실DB에서 가상 B 한 건의 변조·삭제 복원 SQL 시험이 통과했습니다. 운영 엔진 기기 승인·권한 회수·XDR 집행과 실제 서명된 B의 복원 HTTP 왕복은 미실행입니다.

## 6~9단계별 짧은 설명

6) deviceRegistered가 정확히 true인 기기만 다음 판정을 받습니다. false·누락·문자열 위조는 거부합니다. 실제 엔진 기기 등록 왕복은 미검증입니다.

7) 야간·낯선 네트워크·최근 이상 사건이 겹치면 재인증을 요구합니다. 외국 지역만으로 차단하지 않으며, 미상 출처를 정상으로 단정하지 않습니다. 가상 정상·이상·재인증 사건을 검사했습니다.

8) 개별 메모와 읽기 공지를 구분하고, 전체 목록·공지 쓰기·강사 자료·쿼리 우회를 판정기에서 거부합니다. 메모 API는 검증된 소유자로 조회·수정·삭제를 제한합니다. route_not_allowed의 운영 등록부 등록 여부는 미확인입니다.

9) 같은 주체의 GET이 어느 10분 구간에서든 120건을 넘으면 회수를 제안합니다. 경계값·다른 주체·분산 사건을 검사했습니다. 실제 엔진 회수 집행은 미연결입니다.

## 10~12단계 추가 입력

10) 정책 사본의 해시와 변경 범위를 확인한 뒤 시험 사본만 복원하고 사본과 재대조합니다. POST /api/restore는 서명된 심판 B의 최초 메모 한 건을 ID·소유자·내용 해시 대조 후 복원합니다. 정책 사본 복원·모의 API 검사·복구 후 1~9단계 재시험(38/38)과 실DB 변조·삭제 복원 SQL 시험이 통과했고, 실제 서명된 B의 HTTP 왕복은 미실행입니다.

11) 설치형 웹앱(manifest·오프라인 안내)에 기기 승인을 붙였습니다. 기기 키는 내보낼 수 없는 형태로 페이지 메모리에만 두고, 비밀번호 재확인과 개인키 보유 서명을 거쳐 서버가 승인 기록을 남깁니다. 보호 API는 승인 기기의 메서드·경로·본문 서명만 받아 서명 없는 요청, 서명 뒤 경로·본문 변경, 위조 서명을 거부합니다(로컬·모의 검사). ALEPH SDP 엔진의 기기 승인 API와는 연동하지 않았습니다.

12) 이번 단계에서 한 일: 로그인한 사용자의 메모·백업·복원 건수를 서버에서 조회하는 작전실과 재검사표를 추가했습니다. 본문·계정 ID·토큰은 집계 화면 응답에서 제외했습니다.

12) 막힌 점: 운영 엔진의 기기 승인·재인증 왕복·접속 회수·XDR 집행 경로가 제공 계약에 없어 실제 연동을 검증하지 못했습니다. 심판 점수를 로컬 테스트 결과로 대신 표시하지 않았습니다.
